# Сайт timurpanin.ru — чистый HTML, CSS и JS

Статический сайт без сборки и зависимостей. Внешний вид и разметка 1:1 с версией на Astro.

- `*/index.html`, `404.html` — страницы
- `css/style.css` — все стили
- `js/case.js` — страница кейса: просмотр скриншотов, подсветка раздела в содержании
- `js/contact.js` — кнопка «Скопировать» на странице контактов
- `fonts/`, `images/` — шрифт Golos Text и изображения

Пути относительные: сайт открывается двойным кликом по `index.html`, без сервера.
Исключение — `404.html`: на GitHub Pages он показывается на любой глубине URL, поэтому в нём
пути абсолютные (`/css/style.css`), и при открытии файлом он будет без стилей — это нормально.
На GitHub Pages публикуется содержимое папки как есть.
